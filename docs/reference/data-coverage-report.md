## 1. Indicators — what's loaded

> **Auto-generated tables live at [data-inventory.md § 1](data-inventory.md#1-indicators).** Each indicator artifact is listed with its unit, time grain, span, row count, entity count, source host, and a 7-cell **Temporal Richness** meter (`● ● ● ○ ○ ○ ○ 3/7`). Re-run `python -m yen_gov coverage` after every ingest to refresh.

How to read the meter (full rationale in [docs/architecture/backend/coverage.md](../architecture/backend/coverage.md)):

- 7 cells × 3 fiscal years each, FY06–FY26. Rightmost cell is newest.
- A cell is `●` if the indicator has at least one data point inside that bucket.
- Snapshots (single-month CEA series, ad-hoc geodata) carry a `(snapshot)` tag.

### What the categories tell you

Per-indicator definition, methodology vintage, series breaks, denominator, exclusions, sources, and citation live in the canonical CSV store under `datasets/data/datapoints/geo/` and in [`frontend/src/lib/canonical/indicator-allowlist.ts`](../../frontend/src/lib/canonical/indicator-allowlist.ts). The auto-generated `docs/reference/indicators/` markdown tree was retired 2026-05-17 -- see [`docs/reference/indicators/README.md`](indicators/README.md). This section keeps only the **cross-cutting story** of what each topic is for and where it's deep vs shallow. For the row-level shape table (`unit`, `time grain`, `span`, `Temporal Richness`), see [data-inventory.md sec 1](data-inventory.md#1-indicators).

- **Energy (ICED + CEA).** ICED gives long annual per-state series (~10y, FY15–FY25); CEA gives a current-month nameplate-capacity snapshot per fuel. They overlap on installed capacity — ICED is the long-series, CEA is the freshness check. Tier-1/2/3 ICED ingest (2026-05-15) added 8 new endpoints across generation mix, plant-load-factor, CO₂, DISCOM efficiency, RPO compliance, coal/oil consumption, and procurement mix; ~86 ICED endpoints (climate, AQI, water, transport demand, captive, sub-source generation) remain unbound. See [data-inventory.md § 1](data-inventory.md#1-indicators) for the full list.
- **Fiscal (RBI + data.gov.in OGD).** Two distinct shapes: **national long series** (~8 indicators, RBI Handbook / State Finances, FY08–FY26, 7/7 buckets — the canonical "all-states-combined" view) and **per-state series** (`outstanding_debt_pct_gsdp` 31 states FY08–FY26 is the only multi-decade per-state fiscal series; `state_pension_expenditure_inr_crore` 30 states FY05–FY25 ingested 2026-05-16; transfers split across two non-overlapping windows — see the mis-framing-debt row in §5d).
- **Economy + Demography (ICED + RBI Handbook).** ICED ships the `stateWiseDeepDive` bundle (GSDP / GVA / per-capita NSDP, single-base 2011-12, ~FY11–FY24) plus 5 socio-economic siblings ingested 2026-05-15 (per-capita NSDP constant; per-capita private consumption; population-by-sex Census frame; HDI snapshots 2011/2017; national GHG by IPCC sector). RBI Handbook 2024-25 ingest (2026-05-15) added the 4 vintage-spliced **deep-history** NSDP / per-capita-NSDP siblings going back to FY 1994–95, with `series_breaks[]` declaring the four MoSPI rebase boundaries (1993-94 / 1999-2000 / 2004-05 / 2011-12) and `vintage` per row. Pair the spliced and single-base siblings depending on whether you need depth or single-base purity.
- **Prices / inflation (RBI Handbooks, 2026-05-16).** 1 artifact — `prices/cpi_inflation_pct` (post-PR-B8 facetted shard) carries state-level CPI sub-index inflation rates (`general` / `food` / `fuel` / `housing_urban` facets) across 34 states × 11y. All `direction: "neutral"` per Hans's framing — inflation is intrinsically directionless; what matters is direction-of-change vs the 4% target. The 3 national index-level series (CPI-Combined / CPI-IW / WPI All-Commodities) previously surfaced here were retired in PR-D1; no canonical national-inflation successor is planned.
- **Health / vital statistics (SRS via RBI Handbook, 2026-05-16).** 5 artifacts — Crude Birth Rate, Crude Death Rate, IMR, TFR (calendar-year, 35 states × ~20y; SRS Office of the Registrar General); plus state public health expenditure (fiscal-year, 34 states × 8y). IMR is `lower_is_better`; the others are `neutral` (CDR is age-confounded, CBR/TFR drop naturally with development). MMR + Life Expectancy + Doctors-at-PHCs deferred from this batch on shape grounds (multi-year SRS windows, multi-sheet workbooks).

### 5d. Known interpretation risks (loaded but read wrong without renderer guardrails)

These artifacts are on disk and schema-valid, but the citizen will read them wrong unless the renderer carries the framing below.

| Artifact | Mis-framing risk | Corrective framing the UI must carry |
| --- | --- | --- |
| `economy/state_per_capita_nsdp_current_inr` (any current-prices PCNSDP) | "Current prices" includes inflation; a state that grew 0% real but had 6% inflation looks like 6% growth | "Current prices include inflation. For real change, switch to constant prices." Default render should pair current + constant or default to constant. |
| `economy/state_nsdp_*` and `_per_capita_nsdp_*_long` (vintage-spliced) | Citizens compute YoY across MoSPI rebase boundaries (1993-94 / 1999-2000 / 2004-05 / 2011-12) and read the methodology jump as economic reality (Rosling straight-line instinct) | Render the four rebase boundaries as visible vertical breaks **on the line itself, not in a footnote**; disable hover-Δ across them. Per-row `vintage` tag must surface in tooltip. |
| `economy/state_nsdp_*` for Telangana (pre-FY15) | Back-projected from undivided AP — naive reader sees "Telangana growth" before the state existed | Per-row badge on hover: "State did not exist in this form in this year — value is back-projected from undivided AP." |
| `economy/state_nsdp_*` for J&K (post-FY20) | Covers UT-only post-2019-20; not comparable to pre-FY20 state-level figures | Per-row coverage-change badge with the explicit boundary year. |
| `prices/cpi_inflation_pct` | Citizens read "high inflation = bad governance"; in fact CPI is national methodology executed in each state with limited state-level policy levers; the `housing_urban` facet has no rural counterpart by NSO methodology | "Inflation in your state vs the RBI's 4% medium-term target — neither high nor low is automatically good; food/fuel are largely set by national / global conditions. Housing CPI is urban-only." |
| `fiscal/state_pension_expenditure_inr_crore` | Absolute ₹ Crore favours large states; the OPS / NPS debate is fought on the **ratio to revenue receipts**, not the level | Default to "% of state revenue receipts. Above ~12% is the structural-stress threshold most fiscal economists use." |
| `fiscal/centre_transfers_gross` vs `fiscal/net_transfers_from_centre` | Two different definitions, two different windows (FY17–23 vs FY24–26), no overlap; spliced-on-same-axis reading creates a fake trend | Either ship a composed view with a visible methodology join, OR never render them on the same axis. Methodology badge mandatory. |
| `fiscal/outstanding_debt_pct_gsdp` | GSDP denominator is each state's own MoSPI base year; sub-1pp YoY moves are inside the noise band | "Computed against GSDP at current prices in each state's own base year — treat 0.5pp moves as inside the noise band." |
| `energy/installed_capacity_*_mw` (CEA, single-month snapshot) | Rendered next to ICED's annual line, the snapshot reads as "newest data point in a series" | Distinct snapshot glyph + "as of Mar 2026" pill across choropleth, ranked, and small-multiples; never connect the snapshot to the ICED line. |

## 7. How to refresh / regenerate

| Want to refresh… | Run |
| ---------------- | --- |
| Validate every dataset against its schema | `python -m yen_gov validate` (from `backend/` with the venv) |
| Regenerate the auto election-coverage report ([data-inventory.md](data-inventory.md)) | `python -m yen_gov coverage` |
| Run the full backend test suite | `cd backend && pytest -q` (the two LGD tests above will fail until that pipeline lands; `--deselect` if needed) |
| Run the frontend contract tests (every dataset) | `cd frontend && npm test -- src/contracts/datasets-conform.test.ts` (9,312 tests) |
| Ingest a new assembly-election panel (frozen CSV) | `python -m yen_gov ingest-eci-ae-panel --input <csv> --state <S##> [--delim-id 3 --delim-id 4]` |
| Ingest the 2024 Parliament result | `python -m yen_gov ingest-eci-ls --input <Report-33.csv> --crosswalk <Report-34.csv>` |
| Ingest one historical Parliament year (TCPD panel) | `python -m yen_gov ingest-ls-ge-tcpd --input All_States_GE.csv --year 2019` |
| Ingest a hand-downloaded Section 10 XLSX (2016-2023 AE backfill) | `python -m yen_gov eci-statreport-emit-local <xlsx>` |
| Refill the canonical election-results table from a per-AC JSON corpus | `python -m yen_gov canonical-backfill-eci [--event <id>] [--state <S##>] [--corpus-root <dir>]` |
| Regenerate hand-authored taxonomy CSV bundles | `python -m yen_gov emit-taxonomy` |
