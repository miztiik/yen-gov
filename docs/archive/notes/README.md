# Archived Notes

**Last Updated**: 2026-06-11

This folder stores source-hunt verdicts, recon notes, correction notes, and handover-style evidence that should not be live doctrine.

## Rules for Agents

- Treat these notes as evidence, not authority.
- Prefer notes with reproducible commands, counts, sample rows, and named source files.
- If a note's conclusion is still load-bearing, it should already be distilled into a live architecture, concept, reference, or how-to doc.
- Do not add new active work here. Active work belongs under `TODO`; durable conclusions belong under live docs.
